# Portfolio Website

> Personal portfolio website combining media design, UI/UX and frontend development.

## About

This is my personal portfolio website, created to showcase selected projects, my design background and my growing focus on frontend development.

The project was designed and developed from scratch, from the initial wireframes and visual concept to the final React implementation.

## Tech Stack

* **React** – UI development
* **TypeScript** – type-safe development
* **Vite** – development & build tooling
* **CSS** – styling & responsive layouts
* **Git / GitHub** – version control
* **Adobe XD** – design & prototyping

## My Process

The project follows an iterative workflow:

1. **Concept** – defining the structure, visual direction and user experience
2. **Wireframing** – planning layouts and interactions for desktop and mobile
3. **Development** – translating the designs into reusable React components
4. **Testing & Debugging** – identifying and solving technical and UI issues
5. **Iteration** – continuously improving the design, code and user experience

I deliberately separated the interface into reusable components and used TypeScript to keep the project structured and maintainable.

## What I Learned

This project helped me strengthen my understanding of:

* React components, props and state
* TypeScript and typed component interfaces
* Component architecture and data flow
* Responsive design
* Debugging React and TypeScript applications
* Git and GitHub workflows

Most importantly, I learned to approach frontend development not just from a visual perspective, but also from a structural and technical one.

## 🤖 AI Transparency

AI tools were used during development as an **assistant and learning tool**.

I used AI primarily for:

* Explaining concepts and error messages
* Debugging
* Exploring implementation approaches
* Reviewing and improving code

The **concept, visual design, architecture, implementation decisions, testing and final result remain my responsibility**.

AI-generated suggestions were reviewed, adapted and tested rather than being used blindly.

I believe AI is most valuable when it helps me understand a problem and learn from it, not when it replaces the development process.
